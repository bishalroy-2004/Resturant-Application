# Foodies - Restaurant Application

## Description
Foodies is a MERN stack restaurant web application that allows users to explore dishes, learn about the restaurant, and make table reservations through a responsive and user-friendly interface. It features MongoDB database integration, form validation, and seamless frontend-backend communication.

## Features
- Responsive UI
- Restaurant Information Section
- Popular Dishes Showcase
- Team Section
- Table Reservation System
- Form Validation
- MongoDB Database Integration
- Success & Error Notifications

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Axios
- React Router
- React Hot Toast

## Installation

### Clone the Repository
```bash
git clone <repository-url>
```

### Backend Setup
```bash
cd backend
npm install
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
